# Citadel Notes Flutter client

This project supports **native Android** and the existing **Web companion**. Follow the [repository quick start](../README.md). Native source uses conditional platform adapters; web-only libraries are never imported into the Android build.

The native vulnerable app installs as `online.citadel.classroom.vulnerable`. All intentional weaknesses are marked with exercise/category comments. It has no relationship to the separately assessed homework app.
